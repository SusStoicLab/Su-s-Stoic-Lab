# 读书笔记网页生成器

把一本书做成**单文件 HTML**（无外链、双击即开）。已跑通 7 本：
《思考，快与慢》《分心不是我的错》《如何养育多动症孩子》《The Anti-Planner》×2
《那些古怪又让人忧心的问题（What If?）》《我不是教你诈》。

产出形态不是"书摘页面"，是**能用第二次的东西**：要么是可打印贴墙的行动卡，要么是能导航回查的知识地图。

### ⚠️ 模板复制陷阱

用户常复制上一条指令忘记改内容模块名。遇到"系统1/系统2""锚定/可得性/损失厌恶"这类词时，**先判断它属不属于这本书**：
- 不属于 → 做**等价替换**，并在回复里明确说明替换理由（他接受，但要知道）
- 例：《分心不是我的错》→ 双系统换成"诅咒面 vs 馈赠面"，认知偏误换成"ADHD 八误区"
- 例：《如何养育多动症孩子》→ 换成"7 项执行功能 + 14 条行为指导原则"

**不要为了凑齐用户给的模板而硬套不属于这本书的框架。**

## 起始动作：先核查，再动手

1. 联网查：原书目录、章节结构、作者背景、核心命题、真实金句。**不要凭记忆写内容。**
2. 判断"这是学术书还是工具书" —— 决定走哪套模块（见下）。
3. 若用户给的模板与书的实际内容冲突，**先说再做**。

## 两套皮肤

### A. 学术笔记风（前 3 本）
米色纸感 `#f4ecd8` + 深红书签色带 `#8b2e2a` + 渐变蒙版照片 hero + 卡片网格。
hero 用 AI 生成图书馆照片（5-10 积分/张），处理后 base64 内嵌，文件 260-450KB。
**生成前必须先告知用户积分消耗。**

### B. 漫画手绘风（《Anti-Planner》）
粗黑描边(3px) + 硬阴影(`6px 6px 0 #2B2B2B`) + 圆角 16px 贴纸卡 + 分章主题色。
**全 SVG 手绘小人人，不用 AI 生图** → 82KB 小文件，零积分。

## 图片决策规则（重要）

| 场景 | 方案 |
|---|---|
| 原书是**照片/写实**风格 | AI 生图（先告知积分消耗 5-10/张） |
| 原书是**扁平矢量手绘/漫画**风格 | **手绘 SVG**，别用 AI |
| 需要**多个统一风格的小人/图标** | **手绘 SVG**（可复用、可动画、风格 100% 一致） |
| 当前模型读不了图（Read 图片报 "does not support images"） | 一律 SVG，AI 出图等于盲赌 |
| **用户这次没提 hero 图**（只说"做个网页"） | **默认纯 CSS + SVG 装饰，不主动生图**。省积分，且文件能压到 45KB 以内 |

> 只有前 3 本用了照片 hero（260-440KB）。第 6、7 本用纯 CSS+SVG，只有 42-44KB，
> 用户没提任何不满——**没有 hero 照片完全可接受**，别自作主张烧积分。

**理由**：AI 生图复现不了特定插画师的扁平矢量风格，混进页面会突兀；且看不到生成结果 = 无法验收。

SVG 小人模板见 `references/svg-characters.md`。
**path 命令只有** `M m L l H h V v C c S s Q q T t A a Z z`。
打错成 `O`（想写 Q）会让整条 path 静默失效 —— 必须校验。

## AI 图水印处理

水印位置每次不一样，**先 Read 看图再定方案**（若无法看图，就用保守裁切）：
- 右下角块：整片 crop 掉 `img.crop((0,0,W-220,H-52))`
- 右下+右上小块：邻近像素采样 + 高斯模糊覆盖

流程：裁/糊 → resize 到 1280 宽 → JPEG quality 82 → base64 → 注入模板 → 删中间文件。
脚本见 `scripts/process_hero.py`。

## 🔥 致命坑：JS 里的中文引号

在 `<script>` 里写 `["标题","描述里带"引号"的文本"]` 时，**中文全角引号会被规范化成半角 `"`**，直接截断字符串 → SyntaxError。

**症状**：`node --check` 报 `Unexpected identifier '中文'`。

**修复算法（已验证，只对数据区运行）**：
```python
# 判断 " 是否为真正的字符串定界符：
#   next ∈ ,])};:\n  或  prev ∈ [,({:  → 是定界符，保留
#   否则 → 是内部引号，转 「 或 」（toggle 交替）
```
**⚠️ 绝对不能对整段 script 运行**：会把 render() 里的 `class="empty"` 误判成内部引号并破坏 HTML 属性。
正确做法：先把所有 「」 还原成 `"`，再**仅在数据区**（`const RX = {` 到 `document.querySelectorAll` 之前）跑算法。

**预防**：写数据时就直接用 `「」`，别用 `""`。

## 🔥 致命坑：单次 Write 超约 60KB 会被静默截断

写 105KB 单文件 HTML 时，Write 工具在约 71KB 处**直接截断，不报错**，文件已落盘但不完整
（末尾停在半个 JS 数组里，`</script></body></html>` 全丢）。

**判断标准**：单次 Write 内容超过约 60KB 就拆。

**解法（已验证）**：
1. HTML 主体正常 Write（会截断在 `<script>` 之后的某处）
2. `s.find('<script>')` 定位，截断到该位置
3. JS 单独 Write 成 `_tmp/app.js`
4. Python 拼接：`html[:i] + '<script>\n' + js + '\n</script>\n</body>\n</html>\n'`
5. 删 `_tmp`

**预防**：一开始就拆成「HTML 模板 + JS 文件」两段写，最后拼。

## 其他易错点

- **硬编码条数**："现在就做这三件事" 但某组合只有 2 张卡 → 改动态 `CN[set.length]`（`['零','一','两','三']`）
- **锚点**：导航 href 的 `#id` 必须都存在于正文，校验 `hrefs - ids` 为空
- **base64 占位符**：模板里放 `{{HERO_B64}}`，用脚本注入，别手粘
- **node 版本目录会变**：`~/.workbuddy/binaries/node/versions/22.22.2-2/node.exe` 某次变成 `-3`，
  硬编码路径直接 No such file。**每次用 glob 动态定位**
- **Write 不校验目录存在性**：路径多写一层也照写，静默建出错误目录树。写完核对层级
- **搜索要含英文原名**：有 `en` 字段就纳入索引，否则「支持搜英文」是假的
- **标签别太碎**：某标签只挂 1 条卡会显得空。9 个标签 / 40-55 张卡是舒适区
- **查不到确切答案的章节**：只进「全书脉络」目录区，**不进卡片库**。宁可少收录，不要编

## 验证流程（每次交付前必跑）

```bash
python scripts/verify_html.py "路径/to/文件.html"
```

三步：
1. **JS 语法**：提取 `<script>` → `node --check`
2. **冒烟测试**：mock `document` 后 require，遍历所有交互组合，断言每条都有输出
3. **结构校验**：SVG path 命令合法性（限定在 `<svg>...</svg>` 内匹配 `d=`）/ HTML 标签闭合（注意 path/circle/rect/line/ellipse 自闭合）/ 锚点 href-id 配对

## 内容模块模板（按书调整）

1. 书籍信息（作者/版本/领域/核心命题）
2. 一句话总览（要能独立成立，是全页最重要的一句）
3. **核心框架**（学术书用双面对比；工具书用"关键要点章节"）
4. **概念/指导卡片**（8 张左右，2-3 列网格）
5. 全书章节脉络图
6. 金句引用块（3-6 条，必须真实，核实过出处）
7. 行动启发（要具体到"明天能做什么"，不要"要重视XX"）
8. 适合谁读（**适合/不适合两栏** —— 不适合比适合更有信息量）

**工具书加料**：
- 情绪导航器（按状态分色，点击跳转）
- 互动诊断器（2-3 个问题 → 出对应卡片；**所有组合都要测过**）
- 可打印小卡片（`@media print` 里只保留卡片区）

## 「卡片库」型页面（故事集 / 问答集类书通用）

《What If?》《我不是教你诈》都是这个型：**书本身就是一条条独立条目**，
不适合线性章节笔记，适合做成可筛选可检索的卡片库。

### 两种卡片模板

**A. 问题卡**（What If? 型——每条是一个问题与答案）
```
英文原名（小字斜体 Georgia） + 章节号
标题（中文问题名）
┌ 原文问题（灰底 + 左侧色条）
一句话答案（正文主体）
关键数字（虚线分隔，Georgia 强调数量级）
标签药丸
```

**B. 道理卡**（我不是教你诈型——每条是一个道理，故事只留指向）
```
册数徽章 + 主标签
标题 = 道理本身（一句话，必须是可直接执行的判断句）
白话解释（2-3 句，讲清为什么）
┌ 故事梗概（一句话**主题指向**，不编情节）
出处（故事名 / 章节）
标签
```

> ⚠️ 用户说「不按小故事写，只写梗概」时，**梗概写成主题指向，不要编情节**：
> ✅「讲「一句话从一张嘴走到另一只耳朵」能有多快」
> ❌「小英把秘密告诉同事，第二天全公司都知道了」← 这是编的

### 筛选设计
- 单维度：标签（9 个以内）
- 双维度：册别 × 主题（适合多卷本，如四册系列）
- 必配：搜索框（**中文 + 英文原名**都进索引）+ 随机一条（高亮 + scrollIntoView）
- 空结果要有提示文案，别白屏

### 一次做多本的流程
1. 每本拆成 `_tmp/xx.html`（主体）+ `_tmp/xx.js`（数据）两段写，规避 60KB 截断
2. 一个 `_tmp/build.py` 收口，传参决定构建哪本：`build('wi.html','wi.js','WhatIf_xxx.html')`
3. 全部构建完 → 逐本 `verify_html.py` → 逐本 mock 冒烟 → `shutil.rmtree(_tmp)`
4. 两本的 CSS 变量/卡片类名可复用，但**主色要换**（同系列保持米色底，只换书签色：
   深红 = 通用 / 墨蓝 = 冷眼观察类 / 靛青 = 技术类）

## 本土化替换（英文原版 → 中国场景）

原书场景往往不适用于中国读者，必须做替换表。例（Anti-Planner → 小学高年级）：

| 原书 | 中国替换 |
|---|---|
| 回邮件/报税/预约医生 | 交作业/背课文/整理书包 |
| 和老板沟通 | 和老师沟通/找家长签字 |
| 学会拒绝过度承诺 | **拒绝权在家长手上**，家长替她说不 |
| 自己安排一天 | 她的一天被课表焊死，只优化放学后 2 小时 |
| 找个 accountability buddy | 家长陪坐 / 和同学开视频一起写 |

**若使用者是未成年人，必须加「给家长」章节**：
原版工具书默认读者是能独立行动的成年人。儿童的执行功能要到 25 岁才成熟，
需要家长当「外部执行功能」——方法是给家长用的，不是给孩子的。
