# 3C说服框架

用于需要说服别人做决定、接受提案的场景。核心逻辑：先建立共识，再引入对比，最后给出你的方案。

## 结构

```
Customer（共识/问题）→ Competitor（对比/观点）→ Company（你的方案）
```

## 为什么好用

- 先让听众点头："对，我也这么觉得"
- 再制造张力："但是……"
- 最后给出你的答案："所以我觉得……"
- 听众的心理路径顺畅，不容易产生抵触

## 各部分要点

### Customer（共识/问题）
- **做什么**：找到一个听众也认同的事实、常识、痛点
- **关键点**：必须是"大多数人都会同意"的起点，不是你的个人观点
- **常见错误**：
  - 起点太主观，听众一开始就不认同
  - 起点太泛，没有聚焦到具体问题
  - 起点和后面的方案没有关联

### Competitor（对比/观点）
- **做什么**：引入不同的观点、做法、或者现有方案的局限
- **关键点**：制造"但是"的张力，让听众意识到现有方案不够好
- **常见错误**：
  - 对比太弱，听众觉得"现有方案挺好的啊"
  - 对比太极端，听众觉得你在稻草人论证
  - 没有对比，直接跳到自己的方案

### Company（你的方案）
- **做什么**：给出你的具体方案、建议、行动
- **关键点**：方案要能解决Competitor里指出的局限
- **常见错误**：
  - 方案和前面的对比脱节
  - 方案太复杂，听众消化不了
  - 没有说清楚"为什么你的方案更好"

## 示例

### 说服老板投资新项目
**Customer**：我们都知道，现在市场竞争激烈，如果不持续创新，很快就会被对手超越。

**Competitor**：但目前我们的创新主要集中在产品迭代，缺少对新技术的探索。竞争对手已经在布局AI应用，我们还在用传统方法。

**Company**：建议拿出年度预算的10%，成立一个小型创新实验室，专门探索AI在业务中的应用。半年内如果看不到成果，可以及时止损。

### 说服朋友改变习惯
**Customer**：你一直想提高英语水平，这个目标很明确。

**Competitor**：但你目前的方法是每天背单词，坚持了三个月，实际口语还是没太大提升。因为语言的核心是"用"，不是"记"。

**Company**：建议你把每天背单词的30分钟，改成找一个英语母语者视频聊天30分钟。坚持一个月，你会发现口语进步比背单词快得多。

## 自检清单

- [ ] Customer部分是否找到了听众也会认同的共识？
- [ ] Competitor部分是否制造了足够的张力？
- [ ] Company部分是否解决了Competitor指出的局限？
- [ ] 整个说服链条是否连贯，没有跳跃？
