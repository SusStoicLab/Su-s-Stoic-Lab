# 金字塔框架

结论先行，再展开论据。适用于需要快速抓住注意力的场景。

## 结构

```
结论 → 论据1 → 论据2 → 论据3
```

## 为什么好用

- 听众一开始就知道你要说什么，不会迷路
- 符合"先给答案，再给过程"的高效沟通习惯
- 特别适合时间紧、注意力短的场景

## 各部分要点

### 结论
- **做什么**：一句话概括你的核心观点、建议、决定
- **关键点**：清晰、具体、有立场。不要含糊其辞
- **常见错误**：
  - 结论太模糊，听众不知道你想表达什么
  - 结论太长，超过一句话
  - 结论没有立场，像是"可能""也许"

### 论据
- **做什么**：给出支持结论的理由、证据、案例
- **关键点**：每个论据独立、有说服力、能支撑结论
- **常见错误**：
  - 论据之间有重叠或矛盾
  - 论据太弱，撑不起结论
  - 论据太多，听众记不住（建议不超过3个）

## 示例

### 面试答辩
**结论**：我认为自己适合这个岗位，因为我有三个核心优势。

**论据1**：第一，我有5年相关经验，独立负责过3个百万级项目，从0到1完成全流程。

**论据2**：第二，我擅长数据分析，能用数据驱动决策。上个项目通过数据优化，把转化率提升了30%。

**论据3**：第三，我有跨部门协作经验，能和产品、技术、运营高效配合，项目延期率为0。

### 工作汇报
**结论**：这个季度业绩达标，超额完成目标的120%。

**论据1**：销售额突破500万，主要得益于新客户的开拓，新客户贡献了40%的收入。

**论据2**：客户续约率达到90%，说明产品价值得到认可。

**论据3**：团队人效提升15%，优化了流程，减少了重复劳动。

## 适用场景

- 面试答辩：先说"我适合"，再给理由
- 工作汇报：先说结论，再展开
- 提案建议：先说"我建议"，再给依据
- 快速说服：时间紧、注意力短的时候

## 自检清单

- [ ] 结论是否清晰、具体、有立场？
- [ ] 每个论据是否独立、有说服力？
- [ ] 论据之间是否有重叠或矛盾？
- [ ] 整个表达是否在2-3分钟内能讲完？
