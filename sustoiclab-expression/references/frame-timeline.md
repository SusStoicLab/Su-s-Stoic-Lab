# 时间线框架

按时间顺序组织内容：过去→现在→未来。适用于讲故事、回顾、展望的场景。

## 结构

```
过去（为什么/背景）→ 现在（感受/观点）→ 未来（期望/计划）
```

## 为什么好用

- 符合人类对故事的自然感知：有起因、有发展、有结局
- 容易引发情感共鸣，特别是"过去→现在"的对比
- 适合个人故事、团队回顾、项目总结

## 各部分要点

### 过去（为什么/背景）
- **做什么**：回顾起因、背景、之前的状态
- **关键点**：讲故事，有画面感，让听众"看到"当时的场景
- **常见错误**：
  - 过去讲得太长，变成了流水账
  - 过去和现在没有关联，听众不知道为什么要讲这段
  - 过去太抽象，没有具体的细节和画面

### 现在（感受/观点）
- **做什么**：描述当前的状态、感受、认知
- **关键点**：和"过去"形成对比，让听众看到变化
- **常见错误**：
  - 现在和过去没有对比，听众感受不到变化
  - 感受太抽象，没有具体的情感词
  - 观点和事实混淆，听众分不清

### 未来（期望/计划）
- **做什么**：展望未来、表达期望、给出计划
- **关键点**：让听众看到方向，产生期待或共鸣
- **常见错误**：
  - 未来太空泛，没有具体目标
  - 未来和现在没有关联，像是硬加的
  - 未来太悲观或太乐观，听众不买账

## 示例

### 获奖感言
**过去**：三年前我刚进这个行业的时候，什么都不懂，连基本的代码都不会写。那时候每天加班到深夜，一边学一边做，失败了无数次。

**现在**：今天我站在这里，拿着这个奖，觉得自己真的很幸运。不是因为天赋，而是因为坚持。这三年我学到了，技术不是最难的，难的是在失败的时候还能继续。

**未来**：未来我希望能把这些经验分享出去，帮助更多刚入行的人少走弯路。也期待明年还能站在这里，带着新的作品。

### 项目总结
**过去**：半年前我们启动这个项目的时候，资源非常紧张，团队只有3个人，预算不到预期的50%。很多人觉得这个项目做不成。

**现在**：但今天我们可以骄傲地说，项目不仅完成了，还超额达标。这半年我们经历了无数次加班、争论、甚至吵架，但最终证明，小团队也能做大事。

**未来**：接下来我们会把这个项目的经验沉淀成方法论，复用到其他项目。也希望公司能给这样的创新项目更多支持，让更多小团队有机会证明自己。

### 个人故事
**过去**：我从小就觉得自己是个普通人，成绩一般，长相一般，什么都一般。大学毕业后找了份普通的工作，过着普通的生活。

**现在**：但30岁那年，我突然意识到，如果我一直这样下去，50岁的我会后悔。于是我开始改变，学写作、学演讲、学一切让我成长的东西。

**未来**：今天我可以骄傲地说，我不再是那个"普通人"了。未来我希望继续成长，也希望我的故事能激励更多"普通人"去改变自己。

## 适用场景

- 获奖感言：回顾过去、表达感谢、展望未来
- 项目总结：背景、成果、下一步
- 个人故事：成长、变化、启示
- 团队回顾：从困难到成功，展望下一阶段

## 自检清单

- [ ] 过去是否有画面感，让听众"看到"场景？
- [ ] 现在和过去是否形成对比？
- [ ] 未来是否具体、有方向？
- [ ] 整个故事是否连贯，没有跳跃？
