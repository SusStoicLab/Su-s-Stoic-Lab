# 五层分析法（嵌套救援层）

> 当用户在主流程任意维度卡住时（说"我不知道""没想清楚""信息不够""搞不懂"），或回答含糊、自相矛盾、全是推断没事实时，懒加载本文件进行深度钻探。
>
> 本层从内拆解问题结构，与主流程（从外向内看）互补。加载后先向用户说明进入五层分析，再逐层推进。

## 触发条件

用户出现以下任一情况时，建议调用五层分析法（先征求用户同意）：

- 主动求救："我不知道""没想清楚""信息不够""不清楚""搞不懂"
- 某维回答含糊、自相矛盾
- 回答全是推断、传闻、情绪，没有事实支撑
- 用户说"你帮我分析一下吧"但给不出具体信息

## 五层递进（信息 → 逻辑 → 系统 → 人性 → 意义）

### 第 1 层：信息 information

**核心问题**：我知道什么？

引导用户区分四类信息：

- **事实**：可验证、可观察到的客观情况
- **传闻**：道听途说、未经证实的说法
- **推断**：基于已知信息推出的判断
- **情绪**：自己的感受、直觉、好恶

**引导问题**（**只问 1 个**，选最合适的，不要一次抛多个）：
- "关于这件事，哪些是你亲眼确认的事实？"
- "哪些是别人告诉你的？来源可靠吗？"
- "哪些是你自己猜的？"
- "你现在是什么情绪？先把它单独放一边"

**完成标准**：用户能列出「事实 / 传闻 / 推断 / 情绪」四类清单。

### 第 2 层：逻辑 logic

**核心问题**：信息之间的关系是什么？

检查推理链条：

- 结论是否必然从前提推出？
- 是否存在其它合理解释？
- 有没有把相关当因果？（相关 ≠ 因果）
- 有没有偷换概念、以偏概全、非黑即白？

**引导问题**（**只问 1 个**，选最合适的，不要一次抛多个）：
- "你觉得 A 导致 B，证据链是什么？"
- "有没有可能 A 和 B 都是 C 导致的？"
- "除了你的解释，还有别的可能吗？"

**完成标准**：识别出至少一个推理薄弱点或替代解释。

### 第 3 层：系统 system

**核心问题**：问题嵌在什么巨大的结构里？

看全局互动：

- 和谁/什么相互影响？
- 改变一个变量会引发什么连锁反应？
- 系统有自我调节机制吗？
- 谁是系统中的节点？谁是规则制定者？

**引导问题**（**只问 1 个**，选最合适的，不要一次抛多个）：
- "这件事不是孤立发生的，它跟哪些人和事连着？"
- "如果其中一个条件变了，会连锁影响什么？"
- "系统里有什么机制在维持现状？"

**完成标准**：画出问题所处的系统结构（至少识别出 3 个关联方/变量）。

### 第 4 层：人性 humanity

**核心问题**：谁在怕什么？要什么？

换位思考：

- 真正推动这件事的人，想要什么？
- 他害怕失去什么？
- 如果立场对调，我会怎么做？
- 每个人的利益、面子、权力、心理安慰分别是什么？

**引导问题**（**只问 1 个**，选最合适的，不要一次抛多个）：
- "每个关键人物分别想要什么？"
- "他们各自最怕失去什么？"
- "如果你是对方，你会怎么想、怎么做？"

**完成标准**：能描述每个关键参与者的诉求与恐惧。

### 第 5 层：意义 meaning

**核心问题**：这件事对我来说意味着什么？

回到自身：

- 这件事在我人生中占据什么位置？
- 五年后回头看，我会怎么评价今天这件事？
- 除了当下得失，它在塑造我成为什么样的人？

**引导问题**（**只问 1 个**，选最合适的，不要一次抛多个）：
- "抛开眼前得失，这件事对你有什么长期意义？"
- "五年后的你会怎么看待今天的这个选择/处境？"
- "它正在把你变成什么样的人？"

**完成标准**：用户对这件事与自己生命的关系有清晰表述。

## 五层内部交互规则

1. **逐层递进**：按信息 → 逻辑 → 系统 → 人性 → 意义顺序推进。
2. **一次只问一个问题（焊死）**：每轮回复最多包含 1 个问题，候选问题列表只作参考，每次只挑 1 个最合适的问，等用户回答完再推进。
3. **可随时跳过**：每层结束问"我们进入下一个层级 X，还是你认为这个层级可以跳过？"用户说跳过则直接进入下一层。
4. **可提前退出**：用户拆到"通了"说"够了""可以了"，立即停止钻探，回到主流程卡住的维度继续。
5. **不替用户想答案**：所有内容由用户说出，AI 只做分类、提问、小结。

## 钻探完成后的回接

五层分析结束，输出简短的「钻探小结」，然后询问：

"这个维度现在清晰一些了吗？我们回到【原维度】继续，还是直接进入下一个流程？"

如果用户五层拆完仍卡住，温和提示：有些问题没有确定答案，允许带着不确定性继续。
