# 实事求是 · 从客观实际引出规律

## 核心命题
- **"实事"就是客观存在着的一切事物，"是"就是客观事物的内部联系即规律性，"求"就是我们去研究。**
- **实事求是是思想路线的核心**：一切从实际出发，理论联系实际，坚持在实践中检验真理和发展真理。
- **反对主观主义（教条主义与经验主义）**：不唯书、不唯上、只唯实。
- **三种不老实**：脱离实际的唯书、唯上、唯私，都是不实事求是。
- **改造我们的学习**：有的放矢（"的"是实际问题，"矢"是理论武器），不是无的放矢、也不是有矢无的。

## 可操作步骤
1. **先认"实事"**：把客观存在的事实摆出来，不先入为主贴标签。
2. **找出"是"**：从事实中找出内在联系和规律，不是从书本/口号里找答案。
3. **有的放矢**：让理论/经验服务于这个具体实际，而不是拿理论硬套。
4. **破三不老实**：警惕自己是不是在"唯书、唯上、唯私"。
5. **虚怀观是**：放下"我 already know"，才能看见真实。

## 原文金句与出处
- "'实事'就是客观存在着的一切事物，'是'就是客观事物的内部联系，即规律性，'求'就是我们去研究。"（《改造我们的学习》，1941）
- "我们应当从国内外、省内外、县内外、区内外的实际情况出发……"（《改造我们的学习》）
- "有的放矢"（同上，以"的"喻实际问题，以"矢"喻理论武器）

## 引导问句库
- 在这件事上，"实事"到底是什么？你有没有先把客观事实摆全，还是先有了结论再找证据？
- 你看出的"规律"（是），是从这些事实里长出来的，还是从某本书/某句口号里搬来的？
- 你现在的主张，是在"有的放矢"（服务这个实际），还是在"拿理论硬套"？
- 你有没有在"唯书、唯上、唯私"里掉进某一个？尤其"唯私"——是不是因为利益所以选择性看事实？

## 为什么它能启发你
实事求是是毛选的"总开关"。人最常犯的错，是为维护立场、面子或利益而选择性看事实（唯私），或跪着读权威（唯上），或抱着本本不放（唯书）。它让你先停下来问一句：我是在看事实，还是在看我想看的？这一句能救很多自以为清醒的判断。
