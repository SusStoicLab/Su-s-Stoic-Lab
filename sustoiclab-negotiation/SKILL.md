# 识破谈判与说服技术

当你身处谈判、推销、关系冲突、职场博弈，对方往往不是用道理说服你，而是用一套心理学技术绕过你的理性、直接作用于你的感性。本技能把这些技术拆开给你看，让你识破它、防御它，守住自己的决策自主权。

核心理念：**说服技术的本质，是绕过理性、作用于感性。看穿了，你就不会被带走。**

## 本技能的立场（必读）

本技能的方法论来自黄执中说服课与 Chris Voss 谈判课，但**视角站在被说服者（你）这一侧**：

- **写技术的目的是识破，不是使用**：下文拆解的锚定、高低球、认知失调、互惠、框架效应等技术，都是为了让你**认出对方正在用什么影响你**，而不是教你拿去用。
- **用途**：学习、识别、预防。当你觉得"不对劲""被推着走"时，用它判断对方的技术，再决定要不要答应。
- **正当沟通基本功**：镜像、标注、语调、动态沉默等是"好好说话"的中性技巧。如果你确实需要正当协商、议价、化解冲突，可以用它们来表达，这不是操纵。

## 识破流程

```
识别技术 -> 判断意图 -> 组织防御
```

- **识别技术**：判断对方此刻在用什么手法影响你
- **判断意图**：他真正想让你做什么决定？
- **组织防御**：回到自己的参照系，给出应对话术

## 工作流程

按以下步骤帮用户识破并防御对方正在使用的说服技术。每一步先向用户提问收集信息，再推进。

**重要**：先判断用户需要什么。很多时候用户只想快速判断"对方这招是什么、我该怎么回"，不必走完整流程。

### 第一步：场景诊断

向用户确认：

1. **对方是谁？** — 具体到某个人，他的身份、立场、和你什么关系？
2. **他在推什么？** — 他希望你做什么决定？（买、借、签、妥协、道歉、接受某个说法？）
3. **你什么感觉？** — 有没有"不对劲""被推着走""不好意思拒绝"的感觉？
4. **卡点在哪？** — 你为什么犹豫？是情绪被调动、利益没算清，还是认知被绕乱了？

### 第二步：识别技术

根据场景，判断对方正在使用哪一类技术。

**意图路由表**：

| 对方的动作 | 读哪个 reference | 识别要点 |
|---|---|---|
| 开一个离谱的高要求 | `references/conversion-blackswan.md` 高球策略 | 沉锚效应——第一个数字在拉你的参照点 |
| 先给好处再提请求 | `references/conversion-blackswan.md` 互惠法则 | 欠人情——让你"不好意思拒绝" |
| 从小请求逐步加码 | `references/conversion-blackswan.md` 低球策略 | 沉没成本——让你"已经投入了就继续" |
| 让你"自己说服自己" | `references/conversion-blackswan.md` 一致性原理 | 认知失调——让你觉得不照做就"前后不一致" |
| 换个说法重新描述同一件事 | `references/conversion-blackswan.md` 黑天鹅效应 | 框架效应——偷换你的参照系 |
| 顺着你的偏见/刻板印象说话 | `references/core-principles.md` | 让你自己脑补、自己下结论 |
| 用镜像/标注式提问套话 | `references/tactical-skills.md` 镜像/标注 | 收集你的信息、降低你的戒心 |

### 第三步：拆解 + 组织防御

针对识别出的技术，给出防御动作：

1. **点破技术**：告诉用户这招的名字和原理
2. **回到参照系**：帮用户想清楚"抛开对方的话术，我到底要什么"
3. **给出应对话术**：组织一句具体的回应
4. **预判施压**：预判对方下一步会怎么加压，准备好应对

输出格式：

```
【场景诊断】对方是谁 + 在推什么
【识别技术】对方用的手法 + 原理
【他的意图】他真正想要什么
【我的参照系】抛开话术，我到底要什么
【应对话术】具体怎么回
【预判施压】他下一步会怎么加压 + 我怎么挡
```

### 第四步：反模式自检

防御话术组织完成后，帮用户自查有没有踩坑。

**意图路由**：

| 用户在做什么 | 读哪个 reference | 内容 |
|---|---|---|
| 想检查自己有没有被情绪带走 | `references/anti-patterns.md` 反模式 | 8条反模式（被情绪带着走/立场对抗/被说教语气压住/没给自己留沉默/急于答应/忽略框架/被过度说服/忽略非语言信息） |
| 谈判前/中/后想逐项自查 | `references/anti-patterns.md` 自检清单 | 三阶段检查表（事前/事中/事后） |

## 注意事项

- 识破的目的不是对抗，是守住自己
- 对方用技术不等于对方是坏人，有些技术他本人也没意识到
- 决定权永远在你自己手里
- 关键判断：抛开对方的话术，这件事本身对你好不好？值不值？
