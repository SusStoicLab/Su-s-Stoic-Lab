# 谈判说服

帮你在冲突、谈判、说服场景中,找到对方真正在意的东西,用对的方式把话说到位。

核心理念：**说服不是���,是让对方自己改变**。

## 核心引擎

```
情绪标注(O) -> 听众分析(A) -> 策略选择(S)
```

- **情绪标注**：先觉察对方的情绪,直接说出来,让对方感受到被理解
- **听众分析**：判断对方是反对/中立/支持,选择对应的策略
- **策略选择**：根据场景和目标,从工具箱里挑最合适的技巧

## 工作流程

按以下步骤引导用户完成谈判说服准备。每一步都先向用户提问收集信息,再基于回答推进下一步。

**重要**：先判断用户需要什么,再决定走哪一步。很多时候用户只需要快速组织一个话术,不必走完整流程。

### 第一步：场景诊断

向用户确认：

1. **你在跟谁谈？** — 具体到某个人,而不是"大家"。对方的身份、立场、和你什么关系？
2. **对方现在什么态度？** — 反对(抗拒)、中立(无感)、还是支持(顺从)？
3. **你想要什么结果？** — 让对方道歉？改变决定？接受提案？还是只是缓解关系？
4. **卡点在哪？** — 对方为什么不答应？是情绪问题、利益问题、还是认知问题？

这一步的输出：一句话概括场景和目标。

### 第二步：情绪标注

**关键**：先处理情绪,再处理事情。

根据用户的描述,帮用户识别对方的情绪：

1. **对方现在什么情绪？** — 愤怒、失望、恐惧、焦虑、委屈？
2. **情绪的根源是什么？** — 是利益受损、尊严受挫、还是不安全感？
3. **怎么用"标注"说出来？** — 用"你好像/你似乎/你看上去"开头,把情绪直接说出来

**标注的话术模板**：
- "你好像对这件事很失望……"
- "你似乎觉得这不公平……"
- "你看上去有些担心……"

**标注后的动态沉默**：说完标注,停下来,给对方思考的空间。克制自己的表达欲。

### 第三步：听众策略

根据对方的态度,选择对应的策略。

**意图路由表（按用户意图读对应 reference）**：

| 对方态度 | 读哪个 reference | 核心策略 |
|---|---|---|
| 反对(抗拒、怀疑) | `references/audience-strategies.md` 反对听众 | 辩护->消化->以退为进 |
| 中立(无感、不在乎、犹豫) | `references/audience-strategies.md` 中立听众 | 告知/涉入/比较 |
| 支持(顺从、投入) | `references/audience-strategies.md` 支持听众 | 激励->抵御->行动 |

### 第四步：选择技巧

根据场景和目标,从工具箱里挑最合适的技巧。

**意图路由表（按用户意图读对应 reference）**：

| 用户在做什么 | 读哪个 reference | 核心技巧 |
|---|---|---|
| 收集信息、建立友好关系、缓解对立 | `references/tactical-skills.md` 镜像 | 镜像+标注交替使用 |
| 处理对方情绪、化解冲突 | `references/tactical-skills.md` 标注 | 标注情绪+动态沉默 |
| 需要控制场面节奏、安抚情绪 | `references/tactical-skills.md` 语调 | 四种语调模式 |
| 线上沟通、文字谈判 | `references/tactical-skills.md` 线上 | 时间把控、节奏控制 |
| 需要突破僵局、逆转局面 | `references/conversion-blackswan.md` 黑天鹅 | 寻找改变认知的逻辑点 |
| 需要逐步推进、累积承诺 | `references/conversion-blackswan.md` 高低球 | 沉锚效应+沉没成本 |
| 需要让对方自我说服 | `references/conversion-blackswan.md` 一致性 | 制造认知失调+开放式提问 |

### 第五步：组织话术

根据选定的策略和技巧,帮用户组织具体话术：

1. 先用"标注"处理情绪
2. 再用对应策略推进
3. 给出具体的话术示例
4. 预判对方可能的反应,准备应对

输出格式：
```
【场景诊断】一句话概括
【对方情绪】+ 标注话术
【对方态度】反对/中立/支持
【选用策略】策略名称
【核心技巧】技巧名称
【话术骨架】
- 第一步：标注情绪
- 第二步：推进策略
- 第三步：收束/承诺
【预判应对】对方可能的反应 + 你的应对
```

## 第六步：反模式自检

话术组织完成后,帮用户做深度自检,避免常见错误。

**意图路由**：

| 用户在做什么 | 读哪个 reference | 内容 |
|---|---|---|
| 话术快写完了,需要检查有没有踩坑 | `references/anti-patterns.md` 反模式 | 8条反模式详细分析(先讲道理/立场对抗/说教语气/没有沉默/急于求成/忽略黑天鹅/过度说服/忽略非语言信息) |
| 谈判前/执行中/复盘时需要逐项自查 | `references/anti-patterns.md` 自检清单 | 三阶段检查表(准备/执行/复盘) |

加载后逐条对照反模式检查话术,有问题则修正。

## 注意事项

- 说服不是赢,是让对方自己改变
- 不试图说服别人做死人就能做到的事
- 不试图说服别人做最需要改变的事,而是做最可能的事
- 诚实胜于舒适,说自己真正相信的话
