# 反模式与自检

谈判说服中最容易犯的错误,以及如何自检。

## 反模式(豺狗语言)

这些做法会让说服失败,甚至让关系更糟。

### 1. 先讲道理

**表现**：上来就讲逻辑、摆事实,不顾对方情绪。

**为什么错**：人是在感性层面做决定,然后用理性来合理化。情绪没处理好,道理讲不通。

**怎么避免**：先标注情绪,再讲道理。用"你好像/你似乎"开头,让对方感受到被理解。

### 2. 立场对抗

**表现**："我对你错"的思维,硬说服,一定要让对方接受你的观点。

**为什么错**：对方越被推,越抗拒。说服不是赢,是让对方自己改变。

**怎么避免**：把对立立场转化为合作。用"我们"而不是"你我"。问"我们怎么解决这个问题?"

### 3. 说教语气

**表现**：爹味发言,词尾重音向下,专断式语气。

**为什么错**：对方会觉得被指责、被教育,产生防御和愤怒。

**怎么避免**：用调侃/好奇式语气,词尾上扬。面带微笑,传递友好。

### 4. 没有沉默

**表现**：说完就急着补充,不给对方思考空间。

**为什么错**：对方没有时间消化,会觉得被逼迫。你也可能说太多,暴露底牌。

**怎么避免**：标注后停下来,数5秒。克制自己的表达欲,让对方先说。

### 5. 急于求成

**表现**：想一次说服,不接受渐进。

**为什么错**：大的改变需要时间。一次性说服往往失败,还可能伤关系。

**怎么避免**：用低球策略,从小承诺开始。先让对方答应一件小事,再逐步推进。

### 6. 忽略黑天鹅

**表现**：只在自己框架里想,找不到突破口。

**为什么错**：僵局往往是因为双方都被困在旧框架里。需要新的视角。

**怎么避免**：问自己"有没有另一种方式描述这件事?"用替换、升级、转换的思路,寻找黑天鹅。

### 7. 过度说服

**表现**：对方已经动摇,你还在继续说服。

**为什么错**：说太多会让对方反感,甚至重新坚定立场。

**怎么避免**：对方动摇时,停下来,给对方空间。用沉默收束,而不是继续推。

### 8. 忽略非语言信息

**表现**：只关注说什么,不关注语调、表情、姿态。

**为什么错**：非语言信息比内容本身更先被接收。语调不对,内容再好也没用。

**怎么避免**：全面注意语调、表情、姿态。用调侃/好奇式语气,面带微笑。

## 自检清单

在谈判说服之前和之后,用以下问题检查：

### 准备阶段

- [ ] 我理解对方的立场和情绪吗?
- [ ] 我知道对方最在意什么吗?
- [ ] 我准备了标注情绪的话术吗?
- [ ] 我判断了对方的态度(反对/中立/支持)吗?
- [ ] 我选择了合适的策略和技巧吗?
- [ ] 我准备了预判对方反应的应对吗?

### 执行阶段

- [ ] 我先处理情绪了吗?
- [ ] 我用了标注吗?
- [ ] 我给对方留沉默空间了吗?
- [ ] 我的语气对吗?是说教还是对话?
- [ ] 我有没有立场对抗?
- [ ] 我有没有急于求成?

### 复盘阶段

- [ ] 对方感受到被理解了吗?
- [ ] 我有没有说太多?
- [ ] 有没有找到黑天鹅?
- [ ] 对方有动摇吗?下一步怎么推进?
- [ ] 关系有没有受损?怎么修复?

## 核心提醒

**说服不是赢,是让对方自己改变。**

- 不试图说服别人做死人就能做到的事
- 不试图说服别人做最需要改变的事,而是做最可能的事
- 诚实胜于舒适,说自己真正相信的话
- 先连接,再纠正
