# 愤怒 · 冲突 · 强制力
## §愤怒 — 充分表达愤怒
### 核心原则：刺激 vs 原因
- 他人的行为是**刺激**，不是**原因**。让我们生气的是脑中那些**评判性的想法**。
- 愤怒 = 一个**未满足需要的警报**。所有怒气背后都有一个没被满足的需要 + 一个指责性的想法。
### 表达愤怒的四个步骤
1. **停下来，深呼吸**。什么都别做，不指责不惩罚。
2. **看看我们有哪些评判性的想法**（"他不尊重人""这不公平"）。
3. **与我们的需要连结**（评判背后是什么需要：尊重/平等/连结/安全…）。
4. **表达我们的感受和未被满足的需要**。
> 第 3、4 步之间，常需**先同理对方**——若对方还在情绪里，他听不进你。
### 给自己时间
习惯性反应太快时，慢下来、先想清再开口。

## §冲突 — 化解冲突，调和纷争
### 第一性原则
- **连结优先于解决方案**：先建立双方人与人的连结，「问题多半会自行解决」。
- **满意，而非妥协**：目标是各方需要都被充分满足，没有输家。
### 需要 vs 策略 vs 分析（冲突的核心）
- **需要**：普世共通，不指向特定行动。
- **策略**：某人采取的某个具体行动。
- **分析**：分析/诊断对方 = 用悲剧方式表达未满足的需要 → 升级冲突。
### 化解冲突的五个步骤
1. 表达自己的需要。
2. 不论对方说什么，**设法找出他们真正的需要**。
3. **双向确认**：确认彼此都准确理解了对方的需要。
4. **尽可能同理对方**，让双方都确切了解彼此的需要。
5. 双方需要都澄清后，用**正向的、此刻可回应的行动语言**提出化解策略。
### 调解他人冲突的七要点
1. 明确你的角色 + 对过程的信心。
2. 冲突与你无关。
3. 急救式同理。
4. 追踪进度（可用白板记下需要）。
5. 聚焦当下。
6. 推动对话进程。
7. 打断：情绪激烈时勇于打断，拉回四要素轨道。

## §强制力 — 为了保护使用强制力
| | 保护性强制力 | 惩罚性强制力 |
|---|---|---|
| 目的 | 防止人受伤/受不公 | 让"做错事"的人吃苦头悔改 |
| 假设 | 对方出于**无知**，需**教育** | 对方是坏的，需**惩罚** |
| 例 | 抓住要冲上马路的孩子 | 打孩子、"你真丢脸" |
**惩罚的代价**：引发仇恨敌意；削弱自尊；磨灭善意；只关注外在后果而忽视行为本身价值。
