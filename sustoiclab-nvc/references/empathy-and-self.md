# 同理倾听 + 爱自己
## 同理的本质
同理 = 带着尊重，全然临在地理解对方的体验。**"不去做什么，只是那里"**（佛家语）。
- 同理 ≠ 同情、≠ 头脑上的理解、≠ 给建议/安慰/分析。
- 清空先入为主的成见，给对方足够时间与空间表达。
## 妨碍同理的 11 种行为
倾听时若在做下面任何一件，就**不是**在同理——是在阻断连结：
| 行为 | 典型话术 |
|---|---|
| 给建议 | "我认为你应该…" |
| 比惨 | "这算不了什么，听听我经历的…" |
| 说教 | "如果你这样做，会变成积极体验…" |
| 安慰 | "这不是你的错，你尽力了" |
| 讲故事 | "这让我想到曾经…" |
| 摆脱感受 | "高兴一点，别这么难过" |
| 同情 | "哦，你真可怜…" |
| 询问 | "这是什么时候开始的？" |
| 解释 | "我本来想打电话，可是…" |
| 纠正 | "事情不是这样的" |
## 同理操作
1. **听四要素**：无论对方用什么言辞，都只听他的观察/感受/需要/请求。
2. **复述**：用**探询式**提问反馈（不是下结论的语气）。
3. **持续同理**：先别急着给方案。判据——对方**放松/安静下来/问"还有吗"**才算被充分听见。
4. 当对方说"你别跟我玩心理学那套"——继续同理他这句背后的需要（信任/被理解），别辩解。
## 当对方说"不" / 沉默
- **"不"不是拒绝**：听"不"背后是什么需要挡住了答应你。
- **沉默**：同理对方透过沉默表达的感受和需要，别擅自往坏处想。
---
## 当自己痛苦到无法同理（三选项）
1. **同理急救 / 自我同理**：停顿、深呼吸，关注聆听自己的内心。
2. **非暴力呐喊**：不带指责地大声说出当下的痛苦和迫切需要。
3. **离开现场**：前两者都无效时，暂时离开，获得同理后再回来。
---
## 处理自己的情绪与决策（爱自己）
### 听到不中听的话的四种选择
1. **指责自己** → 内疚、羞愧（豺狗向内）
2. **指责他人** → 愤怒（豺狗向外）
3. **体会自己的感受与需要** → 长颈鹿向内
4. **体会他人的感受与需要** → 长颈鹿向外
### 哀悼 + 自我宽恕（犯错、后悔、自责时）
- **哀悼(mourning)**：连结未被满足的需要，而非自责。
- **自我宽恕**：问「我当时那样做，是要满足什么需要？」理解当初行为也是在满足某个需要。
### "不得不"转化为"我选择"（三步练习）
1. 列出"无趣却又不得不做"的事。
2. 每件前面加「我选择做…」
3. 补全「我选择做…，因为我想要…」，连结背后的需要。
### 情绪自由三阶段
1. **情绪的奴隶**：认为要为他人感受负责。
2. **面目可憎**：拒绝为他人感受负责。
3. **情绪的主人**：发自慈悲而非恐惧/羞愧/内疚地回应他人。
